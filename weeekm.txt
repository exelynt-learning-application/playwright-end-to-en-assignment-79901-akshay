## 2. Apply Test Tags

Example of two smoke tests and two regression tests:

```
const { test, expect } = require('@playwright/test');

test('Student login @smoke', async ({ page }) => {
  await page.goto('/login');
  await expect(page.getByRole('button', { name: 'Login' })).toBeVisible();
});

test('Course search @smoke', async ({ page }) => {
  await page.goto('/courses');
  await expect(page.getByRole('heading', { name: 'Courses' })).toBeVisible();
});

test('Course enrollment @regression', async ({ page }) => {
  await page.goto('/courses');
  // Verify course enrollment workflow
});

test('Payment history @regression', async ({ page }) => {
  await page.goto('/payments');
  // Verify payment history
});
```

## 3. Commands to Run Tests

Run only smoke tests:

```
npx playwright test --grep "@smoke"
```

Run only regression tests:

```
npx playwright test --grep "@regression"
```

Run all tests:

```
npx playwright test
```

## 4. Naming Choices and Explanation

- **tests/** – Contains test cases organized by application feature.
- **pages/** – Contains Page Object Model classes, locators, and page actions.
- **fixtures/** – Contains reusable test setup and custom fixtures.
- **utils/** – Contains reusable helper functions and date utilities.
- **data/** – Contains test data such as user details and course information.

This structure keeps tests, page objects, reusable functions, fixtures, and test data separate. Consistent naming and feature-based folders make the project easier to understand, maintain, debug, and scale for new team members.
