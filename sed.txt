The login helper is incorrectly placed in the `tests/` folder because this folder should contain actual test specification files, not reusable helper functions. It should be moved to a `helpers/` or `utils/` folder, such as `helpers/login.js`, so it can be reused across multiple tests. Similarly, the seeded course JSON file is incorrectly placed in the `pages/` folder because this folder should contain Page Object Model classes that manage page interactions and locators. It should be moved to a `fixtures/` or `test-data/` folder, such as `fixtures/courses.json`. This separation keeps the project organized, makes file purposes clear, avoids confusion, and helps new team members easily understand, find, and maintain the test suite.
