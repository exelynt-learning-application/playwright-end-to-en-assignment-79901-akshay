Playwright Codegen is a discovery tool that records user interactions and automatically generates test code, but its output is not a finished test ready to commit. The generated code usually needs two important improvements: first, replace fragile selectors with reliable locators such as `getByRole()` or `getByLabel()`; second, add proper assertions using web-first assertions like `await expect(page).toHaveURL()` or `await expect(locator).toBeVisible()` to verify the expected results. The test should also be reviewed, cleaned up, and executed to ensure it is reliable before committing.
